# NumPy Statistical Analysis

## Project Overview

This project performs statistical analysis on a numerical dataset using Python and NumPy.

The objective is to understand how NumPy statistical functions can be used to calculate important statistical measures and identify patterns in numerical data.

## Objective

The main objectives of this project are:

- Analyze a numerical dataset using NumPy.
- Calculate basic statistical measures.
- Understand the distribution of numerical data.
- Identify important patterns in the dataset.
- Practice NumPy statistical functions.

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Statistical Functions Used

The following NumPy functions are used:

- `np.mean()` - Calculates the arithmetic mean.
- `np.median()` - Calculates the median.
- `np.std()` - Calculates standard deviation.
- `np.var()` - Calculates variance.
- `np.min()` - Finds the minimum value.
- `np.max()` - Finds the maximum value.
- `np.percentile()` - Calculates percentile values.
- `np.ptp()` - Calculates the range.
- `np.sum()` - Calculates the total.
- `np.average()` - Calculates the average.

## Dataset

The project uses a numerical dataset containing 20 observations:

120, 135, 150, 145, 160, 175, 180, 155, 170, 190, 200, 185, 165, 150, 195, 210, 220, 205, 230, 215

## Analysis Performed

The following statistical measures are calculated:

1. Mean
2. Median
3. Standard Deviation
4. Variance
5. Minimum
6. Maximum
7. Range
8. Quartiles
9. Values above the mean
10. Values below the mean
